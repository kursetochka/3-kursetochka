# Задание к зачету

Задание состоит из двух этапов. Каждый из этапов реализуется и в Octave, и в Python.

\
\
\
Пусть дано разностное уравнение $x(k+1)=a_0⋅x(k)+a_1⋅x(k-1)+...a_n⋅x(k-n)$
\
\
\
Шаг 1. Реализовать скрипт step1.m(py), позволяющий:

а. загрузить коэффициенты из предлагаемого файла coeff.csv,

б. получить траекторию системы до момента времени $k = 100$ при известных начальных условиях  
$x(0) = 1$, $x(-1) = x(-2) = ... = 0$, 

в. экспортировать полученный набор данных.
\
\
\
Шаг 2. Реализовать скрипт step2.m(py), позволяющий:

а. импортировать полученный на шаге 1 набор данных,

б. построить график траектории $x(k)$ в зависимости от моментов времени, добавить и выделить цветом график среднего значения величины x, подписать соответствующие оси координат и добавить легенду

в. экспортировать полученное изображение в формате png в файл result.png.
